# Introdução à Cloud Foundations ☁️

Este módulo reúne os **conceitos fundamentais de Cloud Computing e AWS**, servindo como base para os demais conteúdos do estudo para a certificação **AWS Certified Cloud Practitioner**.

## Conteúdos 

* 📁 **[Cloud-e-Beneficios](./Cloud-e-Beneficios)**: Conceitos fundamentais de Cloud Computing e seus benefícios.
* 📁 **[Amazon-Web-Services](./Amazon-Web-Services)**: Conceitos de Serviços Web, introdução aos serviços da Amazon e modelos de precificação.
* 📁 **[Infraestrutura](./Infraestrutura)**: Arquitetura global da AWS, incluindo Data Centers, Zonas de Disponibilidade e Regiões.
* 📁 **[Responsabilidade-Compartilhada](./Responsabilidade-Compartilhada)**: O modelo de Responsabilidade Compartilhada de segurança entre a AWS e o cliente.
* 📁 **[Serviços-Categorias](./Serviços-Categorias)**: Visão geral das principais categorias de serviços oferecidos pela AWS.
