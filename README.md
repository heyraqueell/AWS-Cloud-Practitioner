# AWS Certified Cloud Practitioner ☁️

Repositório destinado à minha **jornada de estudos para a certificação AWS Certified Cloud Practitioner**.

O objetivo deste projeto é **documentar meu aprendizado, organizar meus resumos e facilitar a revisão dos principais conceitos e serviços da AWS** ao longo da preparação para a certificação.

> Este repositório não tem como objetivo substituir os materiais oficiais da AWS. Seu propósito é registrar o conhecimento adquirido durante os estudos e servir como material de apoio para revisão.

## Estrutura do repositório 

Os conteúdos estão organizados por módulos e temas, acompanhando a evolução dos estudos:

* **[Introdução: Cloud Foundations](./Introdução-Cloud-Foundations):** Fundamentos de Cloud Computing, AWS, infraestrutura global, responsabilidade compartilhada e principais categorias de serviços.

* **[Amazon S3](./Amazon-S3):** Classes de Armazenamento, Buckets, Redundância e Casos comuns.

* **[Amazon EC2](./Amazon-EC2):** Computação na AWS, Amazon Elastic Compute Cloud, Armazenamento, Modelos de preços.

* **[Amazon VPC](./Amazon-VPC):** Redes virtuais na nuvem, Subnets públicas e privadas, Blocos CIDR, Internet Gateway, NAT Gateway, Tabelas de Rotas e Segurança (Security Groups e Network ACLs).

* **Próximos módulos**
  Novos conteúdos serão adicionados conforme o avanço dos estudos.

## Objetivos

* Consolidar os conhecimentos adquiridos durante os estudos;
* Organizar resumos e conceitos importantes da AWS;
* Facilitar revisões para a certificação;
* Registrar minha evolução no aprendizado de Cloud Computing;
* Construir uma base de consulta para estudos futuros.

## Referências

Os conteúdos são baseados principalmente nos **materiais oficiais de preparação da AWS** e na ***Escola da nuvem***.
